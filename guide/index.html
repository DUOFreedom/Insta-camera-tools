使用指南

桌面端不需要命令行，四步走完；安卓端需要先自行构建 APK。第一次建议拿一个短视频试一遍再批量。

开始之前

  • 一张相机卡，或者任何可写的文件夹（只转码不登记时够用）。卡里最好留一对同机型录制、未经本工具处理的 VID_/LRV_ 原片当模板。
  • ffmpeg.exe 与 ffprobe.exe：桌面端缺了会在界面上提示下载，安卓端随应用内置。
  • 够用的磁盘空间：导出的主视频时长与原片相近，另加一份代理文件。
  • 记下相机型号与固件版本：换机型或升级固件后，模板与原片的参数可能变，建议重新取一对原片。
  • 导入前先备份卡里的 fileinfo_list.list 与 .editinfo_list.list，这两个文件是相册的目录。

Windows 桌面端

  1. 1

    首次运行缺 ffmpeg 时界面会提示，点按钮装到系统目录或程序目录即可；也可以手动把 ffmpeg.exe 与 ffprobe.exe 放进 exe 同目录的 bin\ 文件夹。

  2. 2

    把相机卡插到电脑（经读卡器），或者先指定一个输出文件夹。

  3. 3

    拖入要导入的视频（支持多选、也支持直接拖整个文件夹）。

  4. 4

    点「开始」，等进度条走完，再把卡插回相机。

Android 安卓端（需自行构建）

  1. 1

    自行构建 APK 并安装，首次启动需勾选同意使用协议。

  2. 2

    用 USB-C 读卡器接上相机卡，在「存储卡」页选择卡根目录并授权。

  3. 3

    「队列」页添加视频；卡里必须有一对相机原生录制的 VID_/LRV_ 作模板。

  4. 4

    点「开始导入」，完成后拔卡插回相机，打开相册。

首次使用建议先拿一个短视频试一遍，确认相册里能看到、能播放、封面正常，再批量处理。

三个常见误区

  1. 以为文件名对上就行。相机不看文件名，看 inst box 与索引；名字对而结构不对，相册里照样没有。
  2. 以为可以不生成代理文件。相册缩略图与快速预览走的就是代理轨，只写主视频会得到一条没有封面的记录。
  3. 以为导入完不用重新插卡。索引写完后要让相机重读一次，重新插卡或开关机，相册才刷新。

其他现象按常见问题里的顺序排查。
