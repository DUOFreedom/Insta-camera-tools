安卓端仍在打磨，真机导入链路与部分机型兼容性尚未验证完毕，因此暂不随 Release 分发 APK。 仓库内的 Kotlin、Chaquopy Python 与 Gradle 配置是完整可构建的，愿意自己编译的话见构建说明。

桌面端需要 ffmpeg（可自动安装）

启动时若找不到 ffmpeg，界面上会出现一条提示，点按钮可自动下载安装：装到系统目录（需要管理员确认）或装到程序目录。也可以自己放 —— 把 ffmpeg.exe 与 ffprobe.exe 放进 exe 同目录的 bin\ 文件夹。程序按「环境变量 → 注册表登记 → 系统安装目录 → 系统 PATH → exe 目录 → 用户目录」顺序查找，都找不到才提示安装。

两个文件都要：只放 ffmpeg.exe 不够，程序需要用 ffprobe.exe 读取源文件信息。

从源码自行打包得到的哈希会与此不同——PyInstaller 与 Gradle 都会把构建时间写进产物，同样的代码每次构建结果都不一致。请以本页面公布的哈希为准核对 Release 下载的文件。

安装 ffmpeg

程序自己不打包 ffmpeg（体积与许可都不合适），第一次运行会在界面上提示。两种装法：

  1. 点界面上的按钮让程序下载安装。装到系统目录需要一次管理员确认；也可以选「装到程序目录」，不需要提权。
  2. 手动把 ffmpeg.exe 与 ffprobe.exe 放进 exe 同目录的 bin\，或者装进系统 PATH。

两个文件都要：读源文件信息用的是 ffprobe.exe，只放 ffmpeg 会在分析样本那一步就失败。

校验下载

PowerShell 里算一次哈希，与页面上给出的 SHA256 逐字符比对：

PowerShell
Get-FileHash .\instatools.exe -Algorithm SHA256

注意：同一份源码连编两次，exe 的哈希也会不同（嵌入时间戳与签名信息），所以校验值只在同一次发布的文件之间通用，以 Release 页标注为准。

从源码构建

桌面端：Python 3.10+ 与 desktop/requirements.txt（只有 PySide6）， 打包脚本是 desktop/build_qml.bat。 安卓端：JDK 21 + Android SDK，Chaquopy 指向本地 Python 3.11， 完整环境变量与离线构建命令见 docs/BUILD.md。

版本演进见更新日志，第三方依赖与许可证见开源声明。
