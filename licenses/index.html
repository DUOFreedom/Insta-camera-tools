开源声明

项目以 GPL-3.0 发布；界面用 PySide6（LGPL-3.0）；ffmpeg 不在仓库内分发。这里一并说明第三方组件与免责条款。

运行时依赖

运行时依赖及其许可证
组件 版本要求 许可证 用途
Python 3.10+ PSF License 运行环境
PySide6 ≥ 6.5 LGPL-3.0 / GPL-3.0 桌面界面
Qt 6 6.5+ LGPL-3.0 / GPL-3.0 桌面界面底层框架
FFmpeg 7.1（安卓端静态链接） GPL-2.0+（含 libx264 / libx265） 转码与封装；桌面端可自动安装，也可自备
Chaquopy 16.0.0 MIT（运行时）/ 商业（构建插件） 安卓端内嵌 CPython 3.11
Jetpack Compose BOM 2026.03.01 Apache-2.0 安卓端界面
Kotlin 1.9.24 Apache-2.0 安卓端界面语言

构建与开发依赖

构建与开发依赖及其许可证
组件 用途 许可证
PyInstaller 打包为单文件 exe GPL-2.0+ with bootloader exception
pytest 回归测试 MIT
Android Gradle Plugin 安卓端构建 Apache-2.0
Gradle 安卓端构建 Apache-2.0

除上述组件外，共享核心仅使用 Python 标准库（struct、zlib、subprocess、urllib、threading、ctypes、pathlib、dataclasses 等），无其他第三方代码依赖；索引的 protobuf 编解码为自行实现，未引入 protobuf 库。

PySide6 与 Qt 6 采用 LGPL-3.0（亦可按 GPL-3.0 使用），本项目以 GPL-3.0 发布，二者兼容。

致谢

  • YCTS-otree —— 感谢其在影石相机文件格式逆向分析上的公开工作，为理解 inst box 布局与索引 protobuf 结构提供了重要参考
  • FFmpeg —— 转码与封装
  • PySide6 / Qt Quick —— 桌面端界面框架
  • Jetpack Compose —— 安卓端界面框架
  • Chaquopy —— 让 Python 核心跑在 Android 上
  • Insta360 官方社区 —— 设备使用与格式相关的公开讨论
