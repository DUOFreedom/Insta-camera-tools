版本 1.0 · 生效日期 2026-11-08

## 一、这个应用是什么

影石相机工具（instatools）是一个**完全离线运行在你自己设备上**的本地工具。
它把普通视频重新封装成影石 Ace Pro 2 相机相册能识别的原生结构
（转码 VID + LRV、移植 `inst` box、登记相机索引），使你用其他设备拍摄的视频
也能在相机相册里正常出现、播放并显示封面。

项目以 GPL-3.0 开源，源码公开在
<https://github.com/DUOFreedom/Insta-camera-tools>。

**本项目是个人开发的第三方工具，与影石创新科技股份有限公司无任何关联，
未获其授权或认可。** Insta360、Ace Pro 等是影石的商标。

## 二、隐私：我们不收集任何数据

### 2.1 不收集、不上传

本应用：

- **不收集**任何个人信息、设备标识、使用统计或崩溃日志
- **不上传**任何文件。你导入的视频、照片与相机卡内容始终留在本机
- **不集成**任何第三方 SDK、广告、分析或推送服务
- **不申请**通讯录、位置、相机、麦克风、短信等任何危险权限

所有转码、`inst` box 移植与索引写入都在你的设备上由本地进程完成，
不依赖任何服务器。

### 2.2 唯一的网络行为

应用**仅有一处**联网行为，且只为检查是否有新版本：

| 项目 | 说明 |
|---|---|
| 触发时机 | 每次启动时，在后台线程发起一次 |
| 请求目标 | `https://api.github.com/repos/DUOFreedom/Insta-camera-tools/releases/latest` |
| 请求内容 | 一次标准 HTTPS GET，仅读取最新版本号 |
| 发送的数据 | 只有请求头里的应用名与版本号（`User-Agent`），不含任何个人标识 |
| 接收的数据 | GitHub 返回的版本标签、发布页地址 |
| 用途 | 若发现新版本，弹窗询问是否前往下载页面。**不会自动下载或安装任何东西** |
| 失败处理 | 超时、无网络、限流、响应异常时静默跳过，不打扰你，也不重试 |

这是本应用需要 `android.permission.INTERNET` 的唯一原因。

如果你不希望应用联网，可以在系统设置里关闭本应用的网络权限
（或使用系统级防火墙），应用的导入功能不受任何影响——只是不再提示更新。

### 2.3 本地保存的数据

应用在你的应用私有目录中保存两类文件，卸载应用即全部清除：

| 文件 | 内容 | 位置 |
|---|---|---|
| `instatools_consent.json` | 你同意本协议的记录：是否同意、协议版本号、同意时间戳 | `files/` |
| `import.log` | 导入过程的运行日志，用于出问题时排查 | `cache/python/` |

两者都不含个人信息，也不会上传。

### 2.4 存储访问

应用**不申请** `MANAGE_EXTERNAL_STORAGE` 或任何存储权限。
访问相机卡完全依赖 Android 的系统目录选择器（SAF）：
你需要亲自在系统弹窗中选中卡根目录并授权，应用才能读写该目录。
你可以随时在系统设置中撤销该授权。

## 三、你必须知道的风险

### 3.1 会改写相机卡上的文件

导入过程会在你的相机卡上：

1. 新建转码后的 VID / LRV 文件
2. **修改** `DCIM/fileinfo_list.list` 与 `DCIM/.editinfo_list.list` 两个索引文件
3. 可能覆盖同名的既有文件

**导入前请务必备份相机卡 `DCIM` 目录。**
索引文件损坏会导致相机相册显示异常，虽然通常可通过相机格式化恢复，
但卡内素材可能因此丢失。

### 3.2 依赖一对真机原片作模板

导入需要卡上存在至少一对相机自己录制的 `VID_*.mp4` 与 `LRV_*.lrv`，
应用会以它们作为 moov 骨架与 `inst` box 的模板。
若卡上没有任何原生录制素材，导入会失败并提示。

### 3.3 未经完整真机验证

本项目通过改写未公开的文件格式与索引结构实现导入，属于逆向分析的产物。
当前版本的部分能力（包括但不限于：AMBA 字段写入、硬件解码与硬件编码路径）
**尚未在足够多的真机与机型上完成验证**。

可能出现的问题包括：相机不识别导入的文件、相册显示 0KB 条目、
播放黑屏、索引异常等。请先用短视频试导入一次，确认无误后再批量处理。

### 3.4 内容合法性

请确保你对导入的视频内容拥有合法权利，且导入行为不违反你所在地区的法律法规
与影石的用户协议。你对自己导入的内容与后果负全部责任。
