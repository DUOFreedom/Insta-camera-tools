v1.3.0

把普通视频变成影石相机能认的「原生」素材

转码成相机原生结构（VID + LRV）、移植 inst box、登记相机索引。插回相机，相册里能识别、能播放、封面正确。适配 Ace Pro 2 与 GO Ultra：分辨率、帧率、关键帧间隔、编码格式默认从卡里真机原片量出，卡里没有原片时可按机型预设。桌面端已发布，安卓端开发中。

两端同源，一套核心

转码、inst box 移植、索引登记这三件事由同一份 Python 核心实现，桌面端与安卓端各自套一层界面。桌面端已发布，安卓端源码可用但还在打磨。

Windows 桌面端

单文件 exe，PySide6 + Qt Quick 界面，界面语言跟随系统（中文 / 英文）。

界面
PySide6 + Qt Quick，单文件 exe 约 75 MB
语言
跟随系统，可用 INSTA_LANG 覆盖
硬件加速
自动探测 AMF / NVENC / QSV

Android 安卓端开发中

Kotlin + Jetpack Compose 界面，内嵌 Chaquopy CPython 运行同一份导入核心，随包带静态 ffmpeg。 源码可构建，尚未发布安装包。

界面
Compose Material 3，三页：存储卡 / 队列 / 设置
架构
arm64-v8a + armeabi-v7a
硬件加速
MediaCodec 硬解 / 硬编，失败自动回退软解

共享核心位于 shared/：insta_index.py 负责索引 protobuf 解析与重建，instbox/inst_transplant.py 负责 camera_udta 与 inst box 移植，instbox/moov_rewrap.py 负责 moov 骨架重封装。改共享逻辑时桌面端与安卓端要两处同改——两份代码逻辑等价，但并非字节级一致。

相机只认自己录出来的文件

把手机或相机拍的视频拷进卡里，相册里要么看不见，要么能列出来但点了打不开，要么没有封面。

相册里看不见

缺少相机私有的 inst box，文件被当成外部拷入的普通视频，不进相册。

能列出来但点了打不开

编码结构不合规：不是 hvc1、带 B 帧、关键帧间隔错位。相机解码器按「无 B 帧、关键帧固定间隔」设计，不是 hvc1 就不认。

没有封面

缩略图没有写进 inst box，或者写入顺序不对——文件能识别，但播放黑屏。

影石相机工具解决的就是这件事：把任意普通视频重新封装成相机认可的结构，写进相机索引，插回相机后就和原生录制的素材表现一致。

它做三件事，缺一不可

三步是一条链，任何一步缺失都会在相机里露出破绽。

1

转码

做什么
视频流转成 HEVC hvc1 1080p、关掉 B 帧、关键帧间隔对齐；同时生成 H.264 的 .lrv 代理文件。
不做会怎样
相机拒绝播放。
2

移植

做什么
把相机私有 inst box 从模板片移植进新文件，写入缩略图与元数据。
不做会怎样
相机视为外来文件，不显示。
3

登记

做什么
在 fileinfo_list.list 与 .editinfo_list.list 中写入条目。
不做会怎样
相册里不出现。

现在就可以试

桌面端是单文件 exe，双击运行、无需安装。第一次用建议先拿一个短视频走一遍，确认相册里能看到、能播放、封面正常，再批量处理。
