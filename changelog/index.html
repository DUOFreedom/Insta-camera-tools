更新日志

自 v1.2.0 以来的主要变更，按新增、修复、界面、测试分组；末尾是仍然存在的限制。

这一页只列主要变更；逐条提交见 GitHub 提交历史。 版本号目前仍是 1.2.0，下面这组改动已经合并进仓库，尚未单独打 tag。

v1.2.0 之后

新增

  • GO Ultra 适配。规格不再按 Ace Pro 2 的假设写死，改为按卡里原片量出：GOP 从原片的 stss 表实测（主视频 120、代理 10，Ace Pro 2 是 16）， inst box 里记录的 GOP 也写真实值；代理轨的编码与元数据跟主视频一致。
  • 机型预设。界面最上方可选「自动 / Ace Pro 2 / GO Ultra」。选预设后按写死的编码、GOP、分辨率、帧率、音轨数生成； 「自动」仍然优先用卡里原片的实测值。
  • ffmpeg 查找与安装重写。查找顺序改为环境变量 → 注册表 App Paths → 系统目录 → PATH → 程序目录； 下载与安装分离，可选装到系统目录（一次管理员确认）或程序目录（无需提权）。

修复

  • 「自动从存储卡分析」卡住界面：改到后台线程执行，结果回主线程。
  • 模板选择：卡里放着上一轮的产物时，按字典序会挑到旧文件，改成由调用方显式指定样本对并校验配对。
  • 安卓端四处硬化：任务文件原子写入、索引校验不再漏文件句柄、封面渲染校验输入并支持取消、转换线程的并发错误不再被吞掉。
  • 端到端跑通时发现的两处关键帧缺陷：video_gop() 接字符串参数、 QSV/AMF 分支漏了 -g 与 -keyint_min。
  • MCRC 校验和改为按产物自己的 mdat 重算；安卓副本补齐 co64 支持。
  • 序列号定位改用「14 字节序列号紧跟机型名」的强特征，减少误判。

界面与体验

  • 桌面端只保留 QML 界面，删掉并行的另一套界面，避免同一个缺陷修两遍。
  • 补齐缺少的入口：封面选择、断点续跑、卡校验、定位卡、单条移除、硬件编码探测、拖拽添加。
  • 转换中关闭窗口改为二选一：停止并退出，或最小化到托盘继续跑——直接退出会留下写了一半的文件。
  • 封面预览改用本地文件 URL；错误提示不再粘在界面上关不掉。

测试与构建

  • 桌面端测试 177 通过、3 跳过；关键修复都做过「改回缺陷版本 → 测试变红 → 恢复 → 变绿」的回滚验证。
  • 两处需要证明确实生效的地方，从「grep 源码」改成行为测试：造真实的 box 喂进去、真调一次、断言实际参数。
  • 桌面端与安卓端的共享模块加 AST 比对守卫，防止一边改了另一边忘改。

v1.2.0（2026-11-08）

  • 修 AMBA 段的音频帧偏移（+0x20 → +0x54），此前生成的缩略图位置偏移。
  • 修 inst 模块的动态加载路径，打包后不再找不到 instbox。
  • 去掉索引模块里写死的一台真机序列号；安卓端更新检查改用正确的版本号来源。
  • 自动续接序号接上「从卡里最大序号 + 1 开始」。

产物

两个平台的构建产物与验证方式
平台 产物 大小 验证

Android app-release.apk 约 75 MB 单元测试 18 项通过（索引用例因无真机跳过）

已知限制

  • 真机链路未端到端验证：AMBA 字段只做了合成模板的偏移级验证，安卓的硬件编解码带自动回退但没在真机上确认。
  • 安卓端 APK 不随 Release 分发，需自行构建。
  • 安卓端默认回退到调试证书签名，正式分发前必须配置自己的签名。
